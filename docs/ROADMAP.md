# Roadmap

The checklist in the README is the public plan. This page is the same plan in a little more detail.

## v0.1

Menu bar app, global shortcuts, region, window, full screen, repeat last region, loupe, timer, donut, editor, clipboard and save, presets, history, pin windows, settings, and onboarding.

## v0.2

Copy text from a capture, secret detection, effects, share, print, and Open in.

## v0.3

Beautify, measure, live text, scrolling capture, a `shotsmith` command, a `shotsmith://` URL scheme, and watch folders.

## v1.0

Plugin destinations, localisation, an opt-in updater, Homebrew and winget, Mac Shortcuts, and an accessibility pass.
