# Privacy

The free app makes no network requests. The optional update check is not included in this build, and there is no telemetry account.

Redaction, OCR, and search, when those features ship, run on your computer.

Official builds that include Shotsmith Pro may use the network only for the actions you start:

- Sign-in
- Entitlement check on launch and every 24 hours
- Stripe Checkout or the customer portal, opened in the browser
- Uploads, link management, and sync you start
- Apple Translation language packs, downloaded by the operating system

A build you compile from this repository does not include Pro and does not perform those calls.
